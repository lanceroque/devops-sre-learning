# DevOps and SRE Learning Roadmap

This roadmap organizes the repository into broad learning stages. It is not tied to a fixed completion schedule.

Topics may be studied in a different order, revisited, or expanded depending on practical needs and existing experience.

## Stage 1 — Development Workflow Foundations

Topics:

* Git fundamentals
* Repository initialization and configuration
* Branching strategies
* Commit conventions
* GitHub repositories
* Issues and pull requests
* GitLab projects and merge requests
* Markdown and technical documentation
* Repository organization
* Release and versioning fundamentals

Expected evidence:

* Organized learning repository
* Meaningful branch and commit history
* Issue and pull request templates
* Documented Git workflow
* Initial tagged release

## Stage 2 — Systems and Networking Foundations

Topics:

* Linux filesystem and permissions
* Processes and services
* Logs and system troubleshooting
* Bash and PowerShell fundamentals
* IP addressing and routing
* DNS resolution
* HTTP request and response flow
* TLS certificates
* Common network troubleshooting tools

Expected evidence:

* Linux command reference
* Troubleshooting exercises
* Networking diagrams
* DNS, HTTP, and TLS notes
* Reusable diagnostic commands

## Stage 3 — Application and Automation Engineering

Topics:

* Python project structure
* Python version management
* Virtual environments
* Dependency management
* Configuration and environment variables
* Logging and error handling
* Testing
* Command-line applications
* API interaction
* Automation design

Expected evidence:

* Python laboratories
* Tested automation scripts
* Dependency lock files
* Configuration examples
* Documented error-handling patterns

## Stage 4 — Containers and Delivery

Topics:

* Docker fundamentals
* Dockerfile design
* Image layers and caching
* Docker Compose
* Container networking and storage
* Image scanning and security
* GitHub Actions
* GitLab CI/CD
* Build, test, and release pipelines
* Deployment workflow fundamentals

Expected evidence:

* Containerized applications
* Reusable Docker examples
* CI/CD workflows
* Automated tests
* Build and release documentation

## Stage 5 — Infrastructure as Code

Topics:

* Terraform fundamentals
* Providers and resources
* Variables and outputs
* State management
* Modules
* Validation and formatting
* Infrastructure testing
* Security checks
* CI/CD integration
* Local cloud-compatible testing

Expected evidence:

* Terraform laboratories
* Reusable modules
* Validation workflows
* Infrastructure diagrams
* Documented assumptions and limitations

## Stage 6 — Kubernetes and Platform Engineering

Topics:

* Kubernetes architecture
* Pods, Deployments, and Services
* Configuration and secrets
* Networking and ingress
* Storage
* Health probes
* Resource requests and limits
* Autoscaling
* Helm
* RBAC
* Policies
* GitOps concepts
* Internal developer platforms

Expected evidence:

* Kubernetes manifests
* Helm charts
* Troubleshooting exercises
* Architecture diagrams
* Platform engineering notes

## Stage 7 — Observability and Site Reliability Engineering

Topics:

* Metrics, logs, and traces
* Prometheus
* Grafana
* OpenTelemetry
* Alert design
* SLIs and SLOs
* SLAs
* Error budgets
* Incident response
* Runbooks
* Postmortems
* Capacity planning
* Performance testing
* Resilience testing

Expected evidence:

* Dashboards
* Alerting examples
* SLO definitions
* Runbooks
* Simulated postmortems
* Reliability testing notes

## Separate Project Repositories

Substantial capstone and portfolio projects will be created in separate repositories.

Possible project areas include:

* Reliable application delivery platform
* Terraform module collection
* Kubernetes observability platform
* Incident simulation environment
* Cloud automation toolkit
* AI-assisted operations or reliability platform

This learning repository may link to those projects but will not contain their complete implementations.
